# 🤖 ربات تبدیل ویدیو تلگرام

ربات تلگرام **کاملاً رایگان** با پایتون — تبدیل ویدیوی معمولی به **ویدیو مسیج گرد** ⭕️ و برعکس، ارسال نتیجه به کانال/گروه، سیستم حساب پرو با دعوت دوستان، پشتیبانی هوشمند (AI) و پنل ادمین کامل.

> ساخته‌شده با [aiogram 3](https://docs.aiogram.dev/) + SQLite + ffmpeg — بهینه برای هاست رایگان **Railway**.

---

## ✨ قابلیت‌ها

### 🎬 تبدیل ویدیو
| ورودی | خروجی |
|---|---|
| 🎥 ویدیوی معمولی | ⭕️ ویدیو مسیج گرد تلگرام (۶۴۰×۶۴۰، حداکثر ۶۰ ثانیه) |
| ⭕️ ویدیو مسیج گرد | 🎥 ویدیوی معمولی |

- بعد از هر تبدیل، ربات می‌پرسه: «**می‌خوای برات بفرستمش توی کانال یا گروه؟**»
- با دکمه «**آره، بفرست ✅**» از لیست مقصدهای ذخیره‌شده انتخاب می‌کنی و ربات اونجا می‌فرسته
- زیر همون پیام، یک **متن دلخواه** (قابل ویرایش توسط ادمین) با دکمه شیشه‌ای «📖 دریافت راهنما» فرستاده می‌شه؛ با زدن دکمه، **عکس + کپشن** راهنما (هر دو قابل ویرایش توسط ادمین) برای کاربر ارسال می‌شه
- فقط **یه تبدیل همزمان** برای هر کاربر (محافظت از CPU/RAM هاست رایگان)
- فایل‌های موقت خودکار پاک می‌شن

### 📢 مدیریت مقصدها (کانال/گروه)
- افزودن با **فوروارد پیام** از کانال/گروه، یا ارسال **آیدی عددی / یوزرنیم / لینک**
- بررسی خودکار اینکه ربات اونجا **ادمین** باشه (برای کانال حتماً لازمه)
- تعیین **پیش‌فرض ⭐**، حذف، لیست

### ⭐️ سیستم پرو و دعوت (رفرال)
- سهمیه رایگان: **۳ تبدیل در روز** (قابل تغییر توسط ادمین)
- با دعوت **۲ نفر کاملاً جدید** (که قبلاً ربات رو استارت نکردن) → **۱۵ روز پرو**
- بعد از ۱۵ روز، با **۲ نفر جدید دیگه** دوباره ۱۵ روز می‌گیری — **تا ابد ♾️**
- پرو = سقف روزانه خیلی بالاتر + سقف حجم بیشتر
- لینک دعوت اختصاصی: `https://t.me/YourBot?start=ref_123456`

### 💬 پشتیبانی هوشمند (AI رایگان)
با API رایگان و بدون‌کلید [Prexzy](https://docs.prexzyapis.com/) (`/ai/gemini`):
- 💬 **چت پشتیبانی** — جواب فارسی به همه سوالات درباره ربات (و سوالات عمومی)
- ✨ **خلاصه‌سازی متن**
- 🌍 **ترجمه** فارسی ⇄ انگلیسی
- اگه Gemini قطع باشه، خودکار از موتور جایگزین استفاده می‌کنه
- سهمیه روزانه جدا برای AI (پیش‌فرض: ۱۵ رایگان / ۱۰۰ پرو)

### 🛠 پنل ادمین (`/admin`)
فقط برای آیدی‌های داخل `ADMIN_IDS`:
- 📊 **آمار کلی**: کل کاربران، کاربران امروز، فعال ۷ روز اخیر، پروها، تبدیل‌ها
- 📣 **پیام همگانی**: به همه کاربران، با حالت **کپی** یا **فوروارد** + گزارش ارسال
- 👥 **مدیریت کاربران**: جستجو با آیدی/یوزرنیم، مشاهده وضعیت (رایگان/پرو، انقضا، دعوت‌ها) + اعطا/لغو پرو و بن/رفع‌بن
- ⚙️ **محدودیت‌ها**: تغییر سقف روزانه، سقف AI، سقف حجم، تعداد دعوت و روزهای پرو — بدون نیاز به ری‌دیپلوی
- 📝 **لاگ تبدیل‌ها**: ۱۰ تبدیل اخیر
- 📢 **کانال‌های متصل**: مشاهده و حذف مقصدهای همه کاربران
- 💬 **متن‌های ربات**: ویرایش متن استارت و راهنما (با پشتیبانی از `{name}` و...)
- 🖼 **پیام تبلیغ**: تنظیم **متن** پیام بعد از تبدیل (با دکمه «📖 دریافت راهنما») و **عکس + کپشنی** که بعد از زدن دکمه می‌ره + پیش‌نمایش زنده

## 🚀 دیپلوی روی Railway رایگان (گام‌به‌گام)

### قدم ۰ — پیش‌نیازها (۵ دقیقه)
1. **ساخت ربات و گرفتن توکن**: در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده:
   - `/newbot` → انتخاب اسم و یوزرنیم → **توکن** رو کپی کن (شبیه `123456:ABC-DEF...`)
2. **پیدا کردن آیدی عددی خودت** (برای ادمین شدن): به [@userinfobot](https://t.me/userinfobot) پیام بده و عدد `Id` رو کپی کن.
3. یه اکانت [railway.app](https://railway.app/) بساز (با گیت‌هاب وارد شو).

### قدم ۱ — اتصال ریپو به Railway
1. در داشبورد Railway روی **New Project** → **Deploy from GitHub repo** کلیک کن.
2. ریپوی همین ربات رو انتخاب کن و Deploy کن.
3. Railway خودش `Dockerfile` رو پیدا می‌کنه و ایمیج رو می‌سازه (اولین بیلد ۳–۵ دقیقه طول می‌کشه چون ffmpeg نصب می‌شه).

### قدم ۲ — تنظیم متغیرها (Variables)
در صفحه سرویس → تب **Variables** → **New Variable** و این‌ها رو اضافه کن:

| متغیر | مقدار | ضروری؟ |
|---|---|---|
| `BOT_TOKEN` | توکن BotFather | ✅ بله |
| `ADMIN_IDS` | آیدی عددی خودت (چندتایی با کاما: `111,222`) | ✅ بله |

بقیه اختیاری‌ان (مقادیر پیش‌فرض در `config.py`) — اگه خواستی عوض کنی، همه‌شون توی [`.env.example`](.env.example) هستن.

> ⚠️ Railway بعد از تغییر Variables خودش سرویس رو **Restart** می‌کنه.

### قدم ۳ — ماندگاری دیتابیس (مهم! ⚠️)
دیتابیس SQLite داخل فایل `data/bot.db` ذخیره می‌شه. فایل‌سیستم Railway با هر دیپلوی جدید **پاک می‌شه**، پس برای اینکه کاربرها و پروها نپرن:

1. در صفحه سرویس → تب **Volumes** → **New Volume**
2. مسیر مانت: `/app/data`
3. سرویس رو **Redeploy** کن.

✅ حالا دیتابیس برای همیشه می‌مونه.

### قدم ۴ — بررسی لاگ‌ها
تب **Deployments** → آخرین دیپلوی → **View Logs**. باید این‌ها رو ببینی:

```
Database ready at data/bot.db
Logged in as @YourBot (id=...)
Starting polling...
```

و خودت (ادمین) در تلگرام پیام «✅ ربات روشن شد» رو می‌گیری. تمومه! 🎉

### 💰 مصرف پلن رایگان
- ربات در حالت بیکار تقریباً **بدون مصرف** CPUـه (long-polling).
- فقط موقع تبدیل ویدیو CPU می‌گیره؛ با `preset=veryfast` و محدودیت ۲ thread و سقف حجم، برای مصرف معمولی کافیه.
- اگه اعتبارت زود تموم شد: سقف حجم (`FREE_MAX_MB`) رو از پنل ادمین کم کن.

## 💻 اجرای محلی (برای تست)

```bash
# 1) پیش‌نیاز: پایتون 3.11+ و ffmpeg
# اوبونتو/دبیان:
sudo apt install ffmpeg python3-venv

# 2) کلون و نصب
git clone <repo-url> && cd Bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3) تنظیمات
cp .env.example .env
nano .env   # توکن و آیدی ادمین رو بذار

# 4) اجرا
python bot.py
```

│   ├── destinations.py     # افزودن/حذف/پیش‌فرض مقصدها
│   ├── pro.py              # وضعیت پرو و لینک دعوت

├── keyboards/main.py       # همه کیبوردها (فارسی)
├── middlewares/guards.py   # ساخت خودکار کاربر + چک بن
├── services/
│   ├── converter.py        # دستورات ffmpeg (گرد ↔ معمولی) + محافظ منابع
│   ├── promo.py            # پیام بعد از تبدیل (متن + دکمه راهنما → عکس و کپشن)
│   └── ai_client.py        # کلاینت Prexzy Gemini (+ موتور جایگزین)
├── utils/                  # تاریخ شمسی‌نما، اعداد فارسی، حافظه موقت
├── Dockerfile              # ایمیج پایتون + ffmpeg
├── railway.toml            # کانفیگ دیپلوی + ری‌استارت خودکار
├── requirements.txt        # وابستگی‌های سبک (aiogram، aiosqlite و...)
└── .env.example            # نمونه متغیرها

## ⚙️ جدول متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات (ضروری) |
| `ADMIN_IDS` | — | آیدی عددی ادمین‌ها با کاما (ضروری) |
| `BOT_USERNAME` | خودکار | یوزرنیم ربات بدون `@` — پشتیبان لینک دعوت (معمولاً لازم نیست) |
| `FREE_DAILY_LIMIT` | `3` | سقف تبدیل روزانه رایگان |
| `PRO_DAILY_LIMIT` | `50` | سقف تبدیل روزانه پرو |
| `AI_FREE_DAILY` | `15` | سقف AI روزانه رایگان |
| `AI_PRO_DAILY` | `100` | سقف AI روزانه پرو |
| `FREE_MAX_MB` / `PRO_MAX_MB` | `20` | سقف حجم ویدیو (حد تلگرام: ۲۰ مگ) |
| `MAX_INPUT_SECONDS` | `300` | حداکثر طول ویدیوی ورودی (ثانیه) |
| `INVITES_FOR_PRO` | `2` | تعداد دعوت لازم برای پرو |
| `PRO_DAYS` | `15` | روزهای پرو هر دوره |
| `TIMEZONE` | `Asia/Tehran` | مبنای ریست روزانه |
| `DB_PATH` / `TEMP_DIR` | `data/bot.db` / `temp` | مسیر دیتابیس و فایل موقت |

> 💡 بیشتر این‌ها رو می‌تونی بعداً از **پنل ادمین → ⚙️ محدودیت‌ها** عوض کنی، بدون ری‌دیپلوی!

## ❓ عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| ربات جواب نمی‌ده | لاگ Railway رو ببین؛ مطمئن شو `BOT_TOKEN` درسته و فقط **یه نسخه** از ربات روشنه (دو نسخه همزمان = تداخل) |
| `BOT_TOKEN is not set` | متغیر `BOT_TOKEN` رو در Variables ست کن و Redeploy بزن |
| بعد از دیپلوی کاربرها پریدن | Volume روی `/app/data` نساختی — قدم ۳ بالا 👆 |
| «نتونستم بفرستم» موقع ارسال به کانال | ربات باید توی کانال **ادمین** باشه (با دسترسی ارسال پیام) |
| ویدیوی بالای ۲۰ مگ خطا می‌ده | محدودیت خود تلگرامه (Bot API ابری)؛ راه‌حل: ویدیوی کم‌حجم‌تر |
| AI جواب نمی‌ده | سرویس رایگان Prexzy گاهی کنده یا قطعه؛ چند دقیقه بعد دوباره تلاش کن |
| خطای `Conflict: terminated by other getUpdates` | دوتا ربات با یه توکن روشنه؛ یکیش رو خاموش کن |

## 📝 نکات فنی

- **ری‌استارت خودکار**: `railway.toml` با `restartPolicyType = "ON_FAILURE"` اگه ربات کرش کنه خودش برمی‌گرده.
- **ریست روزانه**: نیمه‌شب به وقت تهران (قابل تغییر با `TIMEZONE`).
- **امنیت**: توکن فقط در env؛ ورودی‌های ادمین اعتبارسنجی می‌شن؛ کاربران بن‌شده در میدل‌ویر بلاک می‌شن.
- **هزینه**: صفر — SQLite، API رایگان بدون کلید، کتابخانه‌های اوپن‌سورس.
